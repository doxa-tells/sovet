## Перед загрузкой удалить (не нужны сайту)

- `Дизайн без названия.gif` — не используется
- `.DS_Store` — системный мусор macOS
- `DEPLOY.md` — эта инструкция

## Куда деплоить (от простого к сложному)

1. **Netlify Drop** — drop.netlify.com: перетащить папку в окно браузера, сайт онлайн через минуту, бесплатно, HTTPS автоматически.
2. **GitHub Pages** — создать репозиторий, загрузить файлы, включить Pages в настройках.
3. **Vercel** — vercel.com, аналогично Netlify.
4. **Свой хостинг / gov-инфраструктура** — залить файлы в корень веб-сервера (Apache/Nginx), ничего настраивать не нужно: сайт статический, без бэкенда и баз данных.

## Важные примечания

- **Лицензия шрифта.** Unica77 LL — коммерческий шрифт студии Lineto. Для публикации в интернете нужна веб-лицензия. Если её нет — перед публичным деплоем замените на бесплатный аналог (например, Inter с Google Fonts), иначе возможны претензии правообладателя.
- **Домен.** После деплоя привяжите домен (например, поддомен на gov.kz согласовывается с ЕПИР ГО; для теста подойдёт бесплатный поддомен netlify.app).
- Видео весит больше всех остальных файлов — при желании его можно сжать (H.264, ~1 Мбит/с) без видимой потери качества.
